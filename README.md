# Coin Quest

A beginner-friendly playable browser-game prototype.

## Play locally
Open `index.html` in a modern browser. No installation or build tools are needed.

## Files
- `index.html` — complete playable game (HTML, CSS, JavaScript).
- `DESIGN_DOCUMENT.md` — one-page game design document.
- `SCREEN_SKETCH.md` — main-screen sketch and feedback states.
- `PLAYTEST.md` — short playtest checklist.

## Controls
- Arrow keys or WASD to move.
- Mobile: on-screen arrows.
- Collect 10 coins before 45 seconds; avoid red hazards.
- Click Play again after a round; press R after a round ends.

## Publishing one proof link
Upload this folder to a GitHub repository, then enable GitHub Pages in **Settings → Pages** (deploy from the `main` branch and `/ (root)`). The resulting Pages URL is the playable proof link. Keep this README and all supporting files in the same repository.
