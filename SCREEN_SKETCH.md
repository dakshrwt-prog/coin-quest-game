# Main screen sketch and feedback states

```text
+------------------------------------------------------------------+
| COIN QUEST                         PLAYABLE PROTOTYPE             |
| Score  03        Target 10       Time 31s        Lives ❤️❤️🖤     |
+------------------------------------------------------------------+
|                                                                  |

|                                                                  |
|                         mint player                              |
|             $                              (red hazard)          |
|                                                                  |
|       (red hazard)                    $                          |
|                                                                  |
| Collect the gold. Avoid the red.                                 |
+------------------------------------------------------------------+
| Controls: Arrow keys / WASD                 Press R to restart   |
+------------------------------------------------------------------+

START STATE: dark overlay, “Ready, explorer?”, short rules, Start game.
COIN FEEDBACK: score increases; a gold sparkle burst appears.
HIT FEEDBACK: one heart is lost; player blinks briefly.
WIN STATE: overlay says “Treasure secured!” and offers Play again.
LOSE STATE: overlay says “Run over!” and offers Play again.
```
